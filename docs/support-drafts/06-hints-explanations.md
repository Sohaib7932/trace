# Hints and lesson explanations

Status: Draft — not approved for customer-support retrieval.

The existing learner workflow permits up to three progressive guidance requests
per core session after prediction. Early guidance points toward the concept;
later guidance narrows the investigation. Requests are recorded, including failed
guidance requests. Current learner guidance is labelled fixture guidance.

Hints and explanations help with reasoning; they do not execute a proposed change
or establish verified correctness. The current internal free-form assistant
foundation does not create a customer-facing lesson-chat feature.

Guidance requests are separate from new exercise assignments. A request for help
must not be described as consuming a future daily new-exercise slot.

Owner review needed: confirm authored-hint policy and review any future live wording.
