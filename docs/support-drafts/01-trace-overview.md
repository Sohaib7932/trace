# Trace overview

Status: Draft — not approved for customer-support retrieval.

Trace helps learners read, diagnose, change and verify code themselves. The current
learning journey practices Python/FastAPI request contracts through a Notes lesson
and a nested Tasks transfer lesson.

The learning cycle is Predict → Investigate → Modify → Verify → Transfer → Revisit.
Verification uses observed request results and independently read saved data.
Guidance does not establish correctness or complete a lesson.

Current learner hints are labelled deterministic fixtures. Live AI generation,
free-form lesson chat and customer-support chat are not active learner features.
Generated lesson candidates remain separate from published lessons and assignments.

Owner review needed: confirm customer-facing product wording before approval.
