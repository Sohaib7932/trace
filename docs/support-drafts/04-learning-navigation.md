# Learning session navigation

Status: Draft — not approved for customer-support retrieval.

The Learn area presents the existing Notes request-contract lesson and the nested
Tasks transfer lesson. Completing the original Notes lesson unlocks the transfer
lesson. An active session stays associated with the lesson version it started with.

Commit a prediction before requesting guidance or submitting a correction. Inspect
the shown request and receiving model, make a supported mapping change and run
verification. Returning to the same accessible learner history restores saved work.

Completed or abandoned sessions are read-only. Starting a session is not evidence
that a new daily exercise was assigned. Guest history access depends on the
browser's valid guest identity; account history uses the signed-in account.
