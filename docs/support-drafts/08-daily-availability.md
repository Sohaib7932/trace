# Daily exercise availability

Status: Draft — not approved for customer-support retrieval.

The current learner application offers the existing Notes and Tasks learning
journey. Daily shared generation and automatic new exercise allocation are not
active customer features.

The planned product rule permits at most three new exercise assignments per
learner-local calendar day. Authoritative learner timezone and assignment
semantics still need approval before enforcement can be described as operational.

Hints, explanations, retries, existing exercises, retrieval and review do not
automatically count as new assignments. The current three-guidance-request budget
is a separate rule. This draft does not promise a delivery time, a replenishment
timezone, a paid allowance or a particular mix of daily exercises.

Owner review needed: approve daily allocation and timezone policy before publication.
