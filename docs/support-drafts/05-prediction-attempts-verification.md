# Predictions, attempts and verification

Status: Draft — not approved for customer-support retrieval.

A prediction records the learner's original expectation and reasoning. It stays
preserved after submission. Later corrections are separate numbered attempts;
they do not replace the original prediction.

Verification checks the observed HTTP result, response content, validation errors,
saved row count and independently read stored values. A successful save must agree
with all required evidence. Guidance alone cannot mark an attempt correct.

An unavailable dependency or inconsistent readback is an infrastructure error,
rather than proof of a learner mistake. A failed mapping and a verification error
have different meanings. Use the visible evidence when deciding what to try next.
