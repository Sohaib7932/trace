# Common technical problems

Status: Draft — not approved for customer-support retrieval.

If progress or verification is unavailable, preserve the visible error and the
steps that led to it. A verification infrastructure error does not establish a
wrong learner answer. Return to the same accessible session to inspect saved work
before submitting another change.

If account access fails, use the application's Sign in or recovery guidance.
Guest history may become inaccessible when its browser identity is unavailable;
this does not itself mean that saved history was deleted. Trace does not promise
recovery of a lost guest identity or automatic merging of separate histories.

Do not send passwords, authentication credentials or private account data in a
support question. No service response time, deployment availability guarantee or
automatic account repair is established by this draft.
